# World Wide Travel

A travel agency website, rebuilt from my Assignment 1 HTML/CSS site using
React and Tailwind CSS.

## Features

- Sticky header with smooth-scroll navigation
- Hero section with dark photo overlay and two action buttons
- Featured tour packages, filterable by region (built with `useState`)
- Traveler stepper on every tour card that updates the total price
  (a reusable controlled component)
- Testimonials section with star ratings
- "Plan Your Trip" banner with stats and a custom quote form
- Fully responsive, mobile-first layout

## Built with

- React (JavaScript)
- Vite
- Tailwind CSS
